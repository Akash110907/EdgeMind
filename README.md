# EdgeMind — ESP32-S3 On-Chip Edge AI Processing

Vishwakarma Awards 2026–27 submission · App ID: **VK26-IITI-AHM-0463**

Team: Akash S · Pranov Bhalaji AV · SenthilKumaran J

## Overview

EdgeMind is a battery-powered ESP32-S3 edge-AI device with two input paths: audio captured locally by an INMP441 I²S MEMS microphone, and text or voice messages sent from a phone/laptop over Wi-Fi. Both inputs are intended to feed on-device inference on the ESP32-S3. Only the inference result is sent back to the phone/laptop over Wi-Fi.

```text
[INMP441 microphone] -- I²S audio -------------------+
                                                     v
[Phone/laptop] -- Wi-Fi text or voice message (planned) --> [ESP32-S3]
                                                  [On-device
                                                   inference]
                                                     |
[Phone/laptop] <-- Wi-Fi: result only ---------------+
```

**Current limitation:** the checked-in firmware is still a Phase 1 prototype. `runInference()` currently uses a simple average-amplitude threshold; it is **not TensorFlow Lite Micro inference** and does not recognize keywords or sound events yet. The phone-to-device text/voice input path is not implemented either; only microphone capture and Wi-Fi POST-out are working.

## Hardware

- ESP32-S3 DevKitC-1 N16R8 (16 MB flash / 8 MB PSRAM)
- INMP441 I²S MEMS microphone
- LiPo battery and suitable charging/protection circuit

## Software

- Arduino IDE and Espressif's `arduino-esp32` board package
- ESP32 I²S driver
- `WiFi.h` and `HTTPClient.h`
- TensorFlow Lite Micro is the planned inference runtime; the matching model and audio feature-extraction pipeline are not yet integrated.

## Build and flash the current prototype

1. Open `firmware/EdgeMind_ESP32S3/EdgeMind_ESP32S3.ino` in Arduino IDE.
2. Install **esp32 by Espressif Systems** from Boards Manager.
3. Copy `secrets.h.example` to `secrets.h` in the same folder, then set `WIFI_SSID`, `WIFI_PASSWORD`, and `SERVER_URL`. Do not commit `secrets.h`.
4. Select **ESP32S3 Dev Module** and the correct serial port.
5. Connect the INMP441: SCK/BCLK → GPIO2, WS/LRCL → GPIO15, SD/DOUT → GPIO13, VDD → 3V3, GND → GND, L/R → GND. Change the sketch's pin definitions if your wiring differs.
6. Upload and open Serial Monitor at 115200 baud.

The current sketch requires the private `secrets.h` file to compile. This prototype reports `sound_detected` or `silence` based on amplitude only.

## Planned keyword-spotting model

The standard TensorFlow Lite Micro `micro_speech` example is a **keyword-spotting demonstration** (commonly “yes” and “no”, plus “unknown” and “silence” labels), not a defence sound-event detector. It expects features generated by the corresponding audio frontend; raw PCM must not be passed directly as if it were the model input. See [model/README.md](model/README.md) before integrating any model.

## Security note

Keep Wi-Fi credentials and local server addresses in `secrets.h`, which is ignored by Git. Do not place credentials in the sketch or commit them.
